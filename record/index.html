2. Fill and download

How to upload to GitHub
  1. Unzip the download. You get an audio folder. Do not upload the zip itself.
  2. At the top of the repository (where index.html is), click Add file, then Upload files, and drag the whole audio folder in. If you drag only the files inside, they end up in the wrong place.
  3. GitHub on the web takes up to 100 files at a time, so each zip holds at most 100 files. Upload part 1, then part 2, and so on. They all merge into the same audio folder.
  4. manifest.json is always in part 1 and lists every clip, including the ones already on the site. Always upload part 1.
  5. Check: open your-site/audio/manifest.json. If you see text, it worked. Lines without a clip are read by the device voice.
  6. After remaking clips, download new or changed clips and upload them the same way. File names come from the words and the voice, so nothing collides.
